# 🧮 Smart Calc Pro

A modern, responsive calculator web application with **Voice Calculator** support, built using HTML, CSS, and JavaScript.

## ✨ Features

* 🧮 Basic arithmetic calculations
* 🎙️ **Voice Calculator** — perform calculations using voice commands
* 📱 Responsive design
* ⚡ Fast and smooth calculations
* 🎨 Modern and user-friendly interface
* ⌨️ Easy-to-use calculator controls

##  Technologies

* HTML5
* CSS3
* JavaScript
* Web Speech API

##  About
Smart Calc Pro is a JavaScript-based calculator project designed to provide a simple and interactive calculation experience with both traditional input and voice-based calculation.
